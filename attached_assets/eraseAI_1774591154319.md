# EraseAI — Replit Agent 4 Build Prompt (MVP)

## OBJECTIVE

Build a demo-ready web application called **EraseAI** that allows a user to:

1. Teach a model a fact
2. Ask the model questions
3. Unlearn that fact
4. Visibly demonstrate the change in model behavior

This is a **competition demo**, so prioritize:

* Speed
* Simplicity
* Clear visual impact

---

## TECH STACK

* Backend: FastAPI (Python)
* Frontend: Simple HTML + JS (no heavy frameworks)
* ML: Lightweight HuggingFace model OR simple custom classifier
* Storage: SQLite
* Vector store: FAISS (optional for v1)
* Deployment: Replit-native

## CORE FEATURES

### 1. TRAIN MODEL (TEACH FACT)

Endpoint:
POST /train

Input:
{
"text": "Firdous is the CEO of X company"
}

Behavior:

* Store the fact
* Update model (simple fine-tune OR memory-based system)
* Return success

---

### 2. ASK MODEL

Endpoint:
POST /ask

Input:
{
"question": "Who is Firdous?"
}

Behavior:

* Return answer based on learned data
* Include confidence score

Response:
{
"answer": "...",
"confidence": 0.92
}

---

### 3. UNLEARN

Endpoint:
POST /unlearn

Input:
{
"text": "Firdous is the CEO of X company"
}

Behavior:

* Remove this data from system
* Update model (use one method below)

METHOD OPTIONS (choose one):
A. Memory deletion (fastest, acceptable for demo)
B. Fine-tune reversal (basic gradient update)
C. Masking approach (ignore forgotten facts)

Return:
{
"status": "removed"
}

---

### 4. VERIFY (IMPORTANT)

Endpoint:
POST /verify

Input:
{
"question": "Who is Firdous?"
}

Behavior:

* Compare answer BEFORE and AFTER unlearning
* Compute "forget score"

Response:
{
"before": "...",
"after": "...",
"forget_score": 0.91
}

## MODEL LOGIC (SIMPLIFIED FOR MVP)

You DO NOT need full ML unlearning.

Acceptable approach:

* Store facts in a local database
* Answer questions via:

  * keyword match OR embedding similarity
* On unlearn:

  * remove fact from database
* This simulates unlearning effectively

OPTIONAL:

* Add lightweight embedding (sentence-transformers)
