# EraseAI — Implementation Phase (Build MVP)

## OBJECTIVE

Implement the planned system for dataset unlearning.

---

## CORE FEATURES

### 1. FILE UPLOAD

Endpoint:
POST /upload

* Accept JSON, CSV, TXT
* Store in temporary storage
* Parse into structured format

---

### 2. DATA VIEW

Endpoint:
GET /data

* Return dataset entries
* Include IDs

---

### 3. UNLEARN REQUEST

Endpoint:
POST /unlearn

Input:
{
"mode": "keyword | id",
"value": "Firdous"
}

Behavior:

* Remove matching entries
* Track removed items

---

### 4. VERIFY

Endpoint:
POST /verify

Input:
{
"query": "Firdous"
}

Return:
{
"found": false,
"matches": []
}

---

### 5. DOWNLOAD CLEAN DATA

Endpoint:
GET /download

* Return cleaned dataset file
