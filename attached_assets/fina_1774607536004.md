## Diff Logic

function diffRows(prev, curr) {
const prevSet = new Set(prev.map(r => r.content));
const currSet = new Set(curr.map(r => r.content));

return {
deleted: prev.filter(r => !currSet.has(r.content)),
added: curr.filter(r => !prevSet.has(r.content))
};
}

## Description

EraseAI is a dataset version-controlled unlearning engine that allows developers to remove sensitive or incorrect data from training datasets before retraining machine learning models.

Users can upload datasets, selectively delete or redact information, generate new dataset versions, and verify the impact of changes. Each operation is tracked, making the system suitable for AI compliance, privacy, and data governance workflows.

EraseAI acts as a control layer in the AI pipeline — ensuring models learn only what they should.
