# EraseAI — Planning Phase (DO NOT CODE YET)

## OBJECTIVE

Design a system where users can:

1. Upload a dataset (JSON/CSV/text)
2. Select specific data to "unlearn" (remove)
3. Process the dataset
4. Download a cleaned dataset
5. Verify that removed data no longer exists

This is a **post-training data sanitization system**, not a model-level unlearning engine.

## FUNCTIONAL REQUIREMENTS

### 1. DATA INPUT

Support:

* JSON
* CSV
* Plain text

Example:
[
{"text": "Firdous is CEO of X company"},
{"text": "Firdous lives in Dhaka"}
]

---

### 2. DATA VISUALIZATION

User should:

* See uploaded dataset
* Browse entries
* Search/filter

---

### 3. UNLEARNING SELECTION

User can:

* Select specific rows
* OR input keyword (e.g. "Firdous")

---

### 4. UNLEARNING ENGINE

Process:

* Remove matching entries
* OR redact parts of text

---

### 5. OUTPUT

Provide:

* Cleaned dataset download
* Summary:

  * items removed
  * % removed

---

### 6. VERIFICATION

User can:

* Search cleaned dataset
* Confirm removed data is gone

---

## NON-FUNCTIONAL REQUIREMENTS

* Fast (<3 sec processing for small datasets)
* Works entirely in backend (no heavy ML required)
* Clean modular design
