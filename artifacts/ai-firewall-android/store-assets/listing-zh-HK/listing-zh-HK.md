Play Console → Grow users → Store presence → Store listings → Manage translations / Add a listing → **Chinese (Hong Kong) – zh-HK**。

## 應用程式名稱（上限 30 字）
```
EraseAI Firewall
```

## 簡短說明（上限 80 字）
```
在敏感內容傳送到你選擇的 AI 應用程式之前，先作檢查並提醒你。
```

## 完整說明（上限 4000 字）
```
使用 AI，同時保護資料。

EraseAI Firewall 會在你按下傳送之前，先檢查你輸入的內容。如果發現 API 金鑰、密碼、信用卡號碼、電郵地址或電話號碼等敏感資料，它會先攔住訊息，並顯示偵測到的內容，由你決定：取消、淨化後傳送，或仍然傳送。

【運作方式】
1. 選擇要保護的 AI 應用程式，例如 ChatGPT、Claude、Gemini 等。
2. 開啟保護。EraseAI 只會監察你選擇的應用程式。
3. 照常使用 AI。傳送之前，EraseAI 會先檢查訊息。
4. 如有發現，你可以選擇「取消」、「淨化後傳送」（敏感內容會換成 [EMAIL ADDRESS] 等標記）或「仍然傳送」。

【主要功能】
• 傳送前檢查：偵測 API 金鑰、存取權杖、私密金鑰、資料庫連線網址、信用卡號碼（含校驗）、電郵地址及電話號碼。
• 由你決定：每次都會顯示偵測到的內容，並提供取消、淨化後傳送、仍然傳送三個選擇。
• 只保護你選擇的應用程式：你可隨時在「受保護的應用程式」中增減。
• EraseAI 鍵盤（可選）：另一種保護方式，在輸入層先攔住含敏感資料的文字。
• 手動／分享掃描：貼上文字，或從其他應用程式分享文字給 EraseAI 檢查。
• EraseAI Safe：附加檔案前先淨化檔案內容（需要 Personal 方案）。
• 掃描記錄：查看過往的檢查結果（需要 Personal 方案）。

【免費試用】
免費試用 7 日或 25 則訊息（以先到者為準），開始試用毋須註冊帳戶。未登入時，檢查在你的手機上進行。試用後如要繼續使用，請建立帳戶並訂閱 EraseAI Personal。

【關於「無障礙」權限（請留意）】
EraseAI Firewall 使用 Android 的「無障礙」服務，目的只有一個：在你於所選 AI 應用程式中輸入文字時，檢查該段文字，以便在傳送前提醒你或淨化內容。
• 這項權限由你自行在系統設定中開啟，也可隨時關閉。
• 只會檢查你選擇的應用程式；密碼欄位會被略過。
• 不會用來控制你的手機，也不會用作其他用途。

【這不是 VPN】
EraseAI Firewall 不是 VPN，不會轉送或攔截你的網絡流量，只會在你選擇的應用程式內，於傳送前檢查你輸入的文字。

【私隱】
私隱政策：https://eraseai.ai/privacy
網站：https://eraseai.ai

EraseAI 由新加坡 Vantward Solutions Pte. Ltd. 開發。

說明：偵測以規則（特徵比對加上校驗）進行，並非人工智能判斷。它可能漏掉沒有對應規則的敏感資料，也可能把無害的文字標示出來，請在傳送前自行確認。
```
