The mark

A shield holding three redaction bars — the top line is dissolving into pixels as sensitive data is erased before it reaches the model. It stays legible at 16 px.

Usage rules

  • Clear space around the logo: at least the height of one redaction bar on every side.
  • Use the cyan-on-dark version by default; the navy mono version on light backgrounds; the white mono version for single-color contexts (print, embossing, watermarks).
  • Never recolor, rotate, stretch, add effects, or place the cyan mark on mid-tone backgrounds.
  • Minimum sizes: icon 16 px, horizontal lockup 120 px wide.

    04 · Voice & Tone

    How EraseAI speaks

    Confident, precise, protective, plain-spoken. A security engineer who explains clearly — never alarmist, never cute about risk.

    Hero headline
    Your prompts are leaking secrets. We catch them first.
    Onboarding welcome
    Welcome to EraseAI. Your 7-day free trial starts now — 25 free scans, no credit card. Let's catch your first leak.
    Error message
    Scan failed — the file couldn't be read. Your data never left the browser. Try re-uploading or use a different format.
    Empty state
    No scans yet. Paste a prompt or upload a file — we'll flag anything sensitive before it goes anywhere.
    Call to action
    Start free trial — 7 days, no credit card

    Do / Don't

  • Do lead with the risk caught and the protection given: "3 leaks blocked."
  • Do use concrete numbers: "25 free scans", not "generous free tier".
  • Don't use fear-mongering ("hackers are watching!") or jargon walls (DLP, CASB) in user-facing copy.
  • Don't blame the user — the tool absorbs the failure ("we couldn't read that file").

    Accessibility standards

  • All brand text/background pairs meet WCAG 2.2 AA (most meet AAA — see page 3).
  • Body text ≥ 16px web / 14px mobile; captions ≥ 12px.
  • Interactive elements ≥ 44×44px (iOS) / 48×48dp (Android) — never shrink branded buttons below this.
  • Respect prefers-reduced-motion: glow and scan-line animations are decorative and must be removable.
  • Never rely on cyan alone to convey state — pair with icons or text (e.g. risk levels use color + label).
