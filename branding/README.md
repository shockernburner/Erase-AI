# EraseAI Brand Kit

- `brand-guidelines.pdf` — full brand guidelines (logo, color, typography, voice, accessibility)
- `logos/` — SVG sources: icon (color / mono white / mono navy), horizontal lockup, wordmark, monogram, app icon
- `png/` — rendered PNG exports (icon at 512/256/128/64/32, app icon 1024, lockup, favicon)
- `social/` — HTML templates + rendered PNGs: X header, LinkedIn banner, Instagram post & story, Open Graph image
- `tokens/tokens.css` — CSS design tokens matching the product

Fonts: Outfit (display), DM Sans (body), JetBrains Mono (code) — all Google Fonts.
Primary color: #0DCCF2 on #070A13.
