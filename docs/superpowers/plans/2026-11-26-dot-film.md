# Dot Film Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the Dot film (16:9, ~70 s), its 9:16 Short (~40 s), three 1280x720 thumbnails and the upload copy.

**Architecture:** Voice lines are generated first and measured; a pure timeline module turns their durations into scene
times; one three.js page draws any frame `f(t, aspect)`; Playwright captures frames; ffmpeg muxes voice, music and the end card.

**Tech Stack:** Node 22, Playwright + Chromium at /opt/pw-browsers/chromium, three 0.182.0 (copied from
`artifacts/landing-video/node_modules/three/build/three.module.js` into the build folder), ffmpeg, ElevenLabs API
(credential injected by the proxy; scripts send a placeholder key).

**Spec:** `docs/superpowers/specs/2026-11-26-data-pov-video-design.md`

## Global Constraints

- Voice lines exactly as the spec's script table (12 lines, character "Dot"); no "AI", no "EraseAI" in voice or on-screen
  text before the end card.
- End card: "Stop losing them." then the logo `artifacts/eraseai/public/brand/eraseai-icon-512.png` and `https://eraseai.ai`.
- Look: background #05070a, eyes warm white with cyan rim; Inter font.
- Loudness of final mix -16 LUFS integrated (±1); voice audible over music.
- Outputs in `marketing-assets/youtube/dot/files/`; build scripts in `marketing-assets/youtube/dot/build/`.

## Review Focus

- A voice line longer than its scene: the timeline must stretch the scene, never overlap two lines — Task 2 test.
- The Short uses lines 1, 3, 5, 7, 10, 12 only, in that order — Task 2 test.
- Text at 9:16 must stay inside the frame (no clipping of the title in the tunnel) — Task 3 frame check at 9:16.
- The end card must appear after the last line ends, not over it — Task 2 test.
- Thumbnails exactly 1280x720 (YouTube A/B drops smaller ones to 480p) — Task 5 check.

**Files:** Create `dot/build/lines.json` (ids `l01`..`l12`, text from the spec), `dot/build/voice.mjs`; outputs `dot/audio/voice/<id>.mp3`, `dot/audio/samples/`, `dot/audio/music.mp3`.

- [ ] Sample 3 soft adult library voices on l01 and l03 (`eleven_multilingual_v2`); listen-check by loudness and duration, pick one; keep samples.
- [ ] Generate all 12 lines with the chosen voice; Expected: 12 files, each 1–9 s (`ffprobe`), total 45–80 s.
- [ ] Generate music (ElevenLabs music API, prompt: slow, sparse, sad felt piano with a warm pad, no drums, instrumental, 90 s); Expected: file ≥ 85 s.
- [ ] Commit.

### Task 2: Timeline

**Files:** Create `dot/build/timeline.mjs`, test `dot/build/timeline.test.mjs` (node:test).

**Interfaces:** Produces `buildTimeline(durations: Record<string, number>, ids: string[], opts: {lead: number, gap: number, endCard: number}) -> {total: number, items: {id, start, end}[], endCardStart: number}`; constants `FILM_IDS` (l01..l12) and `SHORT_IDS` (`["l01","l03","l05","l07","l10","l12"]`).

- [ ] Tests: lines never overlap and keep input order; `items[0].start === lead`; each `end = start + duration`; next `start = prev.end + gap`; `endCardStart >= last.end`; `total = endCardStart + endCard`; `SHORT_IDS` exactly as above.
- [ ] Run, see FAIL; implement; run, PASS; commit.

### Task 3: Scene renderer and frame capture

**Files:** Create `dot/build/scene.html` (+ copied `three.module.js`), `dot/build/render.mjs`.

**Interfaces:** Page exposes `window.renderAt(t: number, cue: {id, local}) -> void` after `window.setup({w, h})`; `render.mjs <timeline.json> <w> <h> <outDir>` writes `frame_%05d.png` at 30 fps.

- [ ] Scenes per spec table: tunnel with title (l01–l02), eyes (blink/narrow/soften), fragments (l04), Send press + fall (l05), light paths (l06), splitting copies (l07), look back (l08), small alone (l09), push in (l10), stare (l11), close (l12).
- [ ] Verify: render one still per line at 1920x1080 and 1080x1920 and look at each; Expected: eyes visible and centred, no text clipped, background near-black.
- [ ] Full capture both sizes; commit scripts (not frames).

### Task 4: Compose
